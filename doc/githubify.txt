githubify
================================================================================

Generate GitHub permalinks from the current Neovim buffer.

This plugin is Neovim-only.

SETUP

    Call setup() in your Neovim config:

>
    require("githubify").setup()
<

                                                               *:Githubify*
:Githubify [commit] [use_lineno] [base_url]

    Optional positional args:

    - commit (string): revision to resolve, defaults to HEAD.
    - use_lineno (number): nonzero includes #L<line>, 0 omits line number.
      Defaults to include.
    - base_url (string): override repo base URL. By default uses
      `git remote get-url origin`.

    Side effects:
    - Prints the URL
    - Copies URL to `+` and `*` registers

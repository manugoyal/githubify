# Githubify

Generate GitHub permalinks from the current Neovim buffer.

## Setup

In your Neovim config:

```lua
require("githubify").setup()
```

## Documentation

See `doc/githubify.txt` for full usage and command details.

In Neovim, after installing the plugin, you can also run:

```vim
:help githubify
```

## Compatibility

This plugin is written in Lua and only works on Neovim.

If you need the older Python-based version, use commit:

`6789f71185d4ceb2ac352ac5722de3cb5f2ae68d`
